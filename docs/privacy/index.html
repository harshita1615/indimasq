IndiMasq Privacy Policy

IndiMasq browser extension · Effective 18 November 2026

In short: IndiMasq checks the text you paste or send, and the files you attach, on ChatGPT, Claude and Gemini on your own device. It does not collect, store, sell or transmit your messages or any personal data. It makes no network requests at all.

What IndiMasq does

IndiMasq is a browser extension that warns you before you send Indian personal details, such as Aadhaar, PAN, UPI ID, IFSC, bank account, mobile number, GSTIN or email address, to an AI chatbot, in a message or in an attached file, and can replace them with placeholders like [PAN_1] before anything leaves your browser.

How your text is handled

  • When you paste into or send from the message box on chatgpt.com, claude.ai or gemini.google.com, IndiMasq reads that text and checks it for personal details using rules that run inside your browser.
  • The text is processed in memory only. It is never saved, logged, or sent to IndiMasq, the developer, or anyone else.
  • If you choose Mask, the details are replaced with placeholders in the message box. The link between a placeholder and the original value is kept in that browser tab's memory only and disappears when you close or reload the tab.
  • After you mask something, IndiMasq underlines its placeholders in the chat, such as [PAN_1] in a reply. When you point at one, IndiMasq shows the original value in its own small tooltip. The chat page keeps the placeholder: the value is not put into the page, and nothing is sent to the chatbot or anyone else. You can turn this off with Show real values on hover in the popup.
  • The popup's This chat list shows the placeholders and values of the tab you are looking at. It is read from that tab's memory when you open the popup and is never saved.
  • IndiMasq does not run on any other website and does not read your browsing history. It does not store or send the chat's contents.

How attached files are handled

  • When you attach a text, Word (.docx) or PDF file (with the file picker, by dragging it in, or by pasting it), IndiMasq reads its text on your device. PDFs are opened with PDF.js, which is bundled inside the extension. Nothing is downloaded and nothing is uploaded by IndiMasq.
  • The file is held back from the chat page until the check finishes (usually a second or two). If IndiMasq finds personal details, you choose: attach a safe copy, attach the original, or cancel.
  • In a safe copy, each value is replaced by a placeholder such as [PAN_1]. A Word or text file keeps its formatting. A PDF is redrawn as page pictures with each value covered by its placeholder, so none of the original text, metadata, form fields, comments or attachments is carried over.
  • In files, a value written next to its label (for example "Aadhaar number: …" or "Account number: …") is treated as personal data even if it is not a valid ID number.
  • Locked (password-protected), scanned or very long PDFs cannot be checked: IndiMasq says so, and you decide.
  • Some sites open the file picker through a hidden file input. So that IndiMasq can check files chosen that way, a few lines of IndiMasq's code run in the chat page itself and add that hidden input to the page while it is in use. This code does not read, keep or send anything.
  • Files and their text are processed in memory only, inside the extension, and never stored. You can turn file checks off with Check attached files in the popup.

What is stored on your device

IndiMasq stores only the following, in your browser's local extension storage:

ItemExamplePurpose
On/off setting for each supported site ChatGPT: on Remembers where you want protection
Whether to check attached files and to show real values on hover On Remembers your choices from the popup
Count of items caught, by type PAN: 3 Shown to you in the extension's popup

These are numbers and on/off flags only. No text, values, website addresses or identifiers are stored. This data stays on your device and is not synced. You can clear the counts with Reset counts in the popup, and removing the extension deletes everything.

What IndiMasq does not do

  • No network requests, analytics, tracking, cookies or advertising.
  • No collection, sale or sharing of personal data with anyone.
  • No uploading of your files: only the chat site receives what you choose to attach.
  • No remote code: all of IndiMasq's code, including the PDF reader (PDF.js, by Mozilla, Apache 2.0 licence), is included in the extension package.
  • No account or sign-in.

Permissions

  • Access to chatgpt.com, claude.ai and gemini.google.com: needed to check the text in those sites' message boxes and the files you attach there before they are sent, and to show placeholders' values when you point at them. IndiMasq has no access to other sites.
  • Storage: to save the on/off settings and counts described above, on your device.
  • Offscreen document: a hidden extension page where PDF.js opens attached PDFs and draws safe copies. It runs on your device, keeps nothing between files, and closes itself when idle.

Limitations

IndiMasq reduces the risk of sharing personal details, but it cannot guarantee that every detail is caught. It does not yet detect names, addresses, card numbers or text inside pictures (such as scanned pages or photos). Please check your messages and files before sending.
